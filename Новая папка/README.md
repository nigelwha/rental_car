# Прокат автомобилей — информационная система

Учебный проект по профессиональному модулю ПМ.02 «Осуществление интеграции программных модулей»  
Специальность 09.02.07 «Информационные системы и программирование»

---

##  Описание системы

Информационная система предназначена для автоматизации работы пункта проката автомобилей.  
Реализованы роли пользователей: **Администратор**, **Менеджер**, **Клиент**.

**Основные функции:**
- Авторизация с шифрованием пароля (SHA-256)
- Навигация, зависящая от роли пользователя
- Каталог автомобилей с фильтрацией, поиском и сортировкой
- Бронирование автомобилей клиентом
- Управление арендами менеджером
- Назначение и просмотр штрафов
- Регистрация сотрудников администратором

##  Инструкция по запуску

1. Установите PostgreSQL и pgAdmin.
2. Выполните SQL-скрипт `script.sql` для создания и наполнения базы данных.
3. Откройте решение в Visual Studio.
4. Восстановите NuGet-пакеты (через "Управление пакетами NuGet").
5. Проверьте строку подключения в `Data/ApplicationDbContext.cs`.
6. Соберите и запустите приложение.
